Which Mac download do I need?

Open the Apple menu and choose About This Mac. If you see “Chip” with an Apple M-series name, choose Apple Silicon. If you see an Intel processor, choose Intel.

Install on Mac · unsigned app instructions

Open the DMG and drag Long Haul into Applications. These builds are unsigned and not notarized. If macOS blocks the app, first try System Settings → Privacy & Security → Open Anyway after attempting to open it.

If you trust this download and need to remove its quarantine flag, open Terminal and run the following command after copying the app to Applications. This removes quarantine only from Long Haul and its contents.

xattr -dr com.apple.quarantine "/Applications/Long Haul.app"

Then open Long Haul from Applications. The command is xattr, with the flags -dr. If Terminal reports “No such xattr,” the quarantine flag is already absent.

Install on Windows · unsigned installer instructions

Download and run the Windows EXE. If Microsoft Defender SmartScreen shows “Windows protected your PC,” choose More info, then Run anyway only if you trust this download. Follow the installer and launch Long Haul from the Start menu.

If Windows marks the downloaded installer as blocked, right-click the EXE → Properties → General. If an Unblock checkbox appears, select it, choose Apply, then run the installer again. If your organization blocks installation or no Run anyway option is available, contact its administrator. Keep antivirus protection enabled.

Do I need an internet connection?

Yes. The desktop app loads the live game at xorbit.org/longhaul. It needs an internet connection to play.

How does Discord Rich Presence work?

Open the Discord desktop app and enable activity sharing. Long Haul connects automatically while it is open and displays an elapsed timer and a Play Long Haul button.
